# Таро Онлайн — версия 2

Бесплатный русскоязычный статический сайт: 78 карт, 13 раскладов, 104 страницы. Без npm-зависимостей, платных API, регистрации и подписок.

- Сайт: https://tarot-online-b0zf.onrender.com/
- Единственный репозиторий проекта: https://github.com/3779008-boop/tarot-online
- Render service: `srv-dblusulg1s2s73bitsng`; build `node build.mjs`, publish `dist`, autoDeploy выключен.

## Сборка и проверки

Node.js 22 или новее:

```sh
npm test
npm run build
```

`dist` воспроизводится сборкой и не хранится в Git. Сайт многостраничный: не добавлять SPA rewrite на index.html. Локальная сборка без адреса сайта имеет noindex. `SITE_URL` или `RENDER_EXTERNAL_URL` задаёт production origin для canonical, Open Graph, robots и sitemap.

## Значения и интерпретация

- `cards.txt`: исходные 78 карт, имена, slug, общие значения и советы для разных тем. Последняя числовая колонка оставлена для совместимости формата; новый движок её не использует.
- `upright-contexts.txt`: отдельные прямые значения в отношениях и делах.
- `meanings.txt`: отдельные перевёрнутые значения, советы, состояние, препятствия в отношениях; редакционные категории направлений и смысловые признаки обоих положений. Заголовок файла описывает порядок полей.
- `priorities.txt`: отдельные критерии выбора и акценты совета для каждой карты в обоих положениях.
- `obstacles.txt`: нейтральные препятствия в прямом и перевёрнутом положениях, применимые к делам и общим вопросам. Для отношений используются собственные препятствия.
- `spreads.json`: названия, позиции и их роли, вводные тексты; существующие URL сохранены.
- `engine.mjs`: случайный выбор, восстановление карты дня, чтение позиций, отдельных тем и сочетаний. `readSpread` возвращает ответ, подробности, карты, ограничение и совет.
- `app.mjs`: интерфейс, сохранение карты дня, выбор темы, поиск, аналитика по согласию.
- `style.css`: адаптивное оформление, видимый фокус и reduced-motion.
- `build.mjs`: HTML, оригинальные геометрические SVG-карты и SEO.
- `fixtures.mjs`, `test.mjs`: фиксированные редакционные примеры и технические проверки.

«Да или нет» не суммирует хорошие и плохие карты. Первая карта задаёт условное направление, препятствие и карта действия могут ограничить его. Переворот не инвертирует результат. Категории не являются вероятностями. Отношения различают интерес, эмоциональную открытость, готовность действовать и устойчивость. В периодах учитывается каждый этап; при выборе — возможность и цена каждого варианта.

Система использует редакционные правила, а не ИИ. Она знает выбранную тему и позиции, но не читает мысленно заданный вопрос, личную историю или чужие мысли. Правила важных сочетаний не охватывают все возможные пары. Требуется дальнейшая редакционная работа по реальным отзывам; тесты не доказывают точность гадания.

## Публикация и откат

Перед обновлением записать текущий SHA ветки и проверить, что никто не менял проект параллельно. Исходная опубликованная версия: `144ecde06a88db66eea7b0f762bcf1de55343233`. Она остаётся в истории GitHub; локальная копия исходников также сохранена перед изменениями.

Обновлять только этот репозиторий. После прохождения проверок создать коммит и вручную запустить deploy на существующем Render Static Site. Не менять тарифы и другие сервисы. Для отката можно повторно развернуть предыдущий успешный deploy через Render Dashboard либо создать обычный восстанавливающий коммит из исходного SHA. Не переписывать историю ветки принудительно.

## РСЯ, аналитика и контакты

РСЯ не подключена, модерация не подтверждена. Скрытый контейнер `data-ad-slot="after-reading"` сохранён. Подключение рекламы требует отдельной настройки после одобрения; произвольный CSS-класс не является командой для авторасстановки Яндекса.

`METRIKA_ID` необязателен: без номера внешние аналитические запросы отсутствуют. При наличии Метрика включается после согласия; Webvisor и clickmap отключены. События `spread_start`, `spread_complete` передают только тип расклада. `WEBMASTER_TOKEN` — необязательная верификация Яндекс Вебмастера.

`CONTACT_EMAIL` должен быть публичным адресом, предоставленным владельцем. Не брать личную почту из профиля автоматически. Контакты и политика остаются предварительными до получения адреса и реквизитов. Не утверждать, что рекламная модерация пройдена.

Карта дня хранится только в этом браузере, зависит от его локальной даты. При запрете localStorage показано уведомление. При очистке данных закрепление карты теряется. Иллюстрации геометрические, не историческая сюжетная колода.
